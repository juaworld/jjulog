# 쭈로그 🌱

내 네이버 블로그가 지금 어떤 상태인지 매일 아침 알려주는 나만의 블로그 분석판.

- **쭈로그 점수 & 등급** — 일반 · 준최1~7 · 최적1~3 · 최적1+~4+ (15단계, 추정치)
- **블로그 진단** — 블로그탭 노출, 통합검색 진입, 최근 7일 발행, 발행 공백, 글 최적화, 방문자 추세, 저품질 의심
- **최근 글 분석** — 글마다 블로그탭 노출/누락, 통합검색 노출, 태그 키워드 순위(최대 3개), 글 최적화 점수와 고칠 점
- **키워드** — 내 글 키워드와 관심 키워드의 순위 (+ API 키가 있으면 월 검색량·경쟁도·문서 수)
- **경쟁 블로그 순위** — 내 키워드 검색 30위 안에 자주 함께 뜨는 블로그 최대 20곳과 체급(방문·구독·발행) 비교, 몇 위 · 상위 몇 %
- **구독자 · 오늘/누적 방문 · 방문자 기록 · 점수 기록**

GitHub Actions가 매일 07:00(KST)에 수집하고 GitHub Pages에서 봅니다.

## 설정 (`config.json`)

| 항목 | 설명 |
|---|---|
| `blog_id` | 내 블로그 아이디 (`blog.naver.com/아이디`) |
| `keywords` | 매일 순위를 기록할 관심 키워드 |
| `max_check_posts` | 분석할 최근 글 수 (기본 15) |
| `keyword_check_posts` | 태그 3개까지 순위를 볼 글 수 (기본 10, 나머지는 첫 태그만) |
| `competitors` | 비교할 경쟁 블로그 수 (기본 20) |
| `goal_grade` | 장기 목표 등급 (기본 "최적1") — 로드맵 아래 목표 칸에 몇 주·하루 방문 몇 명이 필요한지 계산 |

config.json 을 고쳐 커밋하면 바로 다시 수집해요. 수동 실행은 **Actions → 쭈로그 수집 → Run workflow**.

## (선택) API 키 — 더 정확하게

키는 코드에 넣지 말고 **Settings → Secrets and variables → Actions → New repository secret** 에 등록하세요.

| 받는 곳 | Secret 이름 | 효과 |
|---|---|---|
| 네이버클라우드 **NAVER API HUB** → Application 생성, Search API 선택 (2026-07부터 개발자센터 신규 신청 종료) | `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET` | 블로그탭 순위 100위까지, 키워드 문서 수 |
| [네이버 검색광고](https://searchad.naver.com) → 도구 → API 사용 관리 | `NAVER_AD_CUSTOMER_ID`, `NAVER_AD_API_KEY`, `NAVER_AD_SECRET` | 키워드 월간 검색량·경쟁도 |

## 점수 계산

| 항목 | 비중 |
|---|---|
| 방문자 규모 (하루 평균, 로그 스케일 · 1만 = 만점) | 30 |
| 키워드 경쟁력 (순위 × 월 검색량 크기) | 30 |
| 블로그탭 노출률 | 10 |
| 통합검색 노출률 | 10 |
| 발행 페이스 (주 7개 = 만점) | 10 |
| 꾸준함 (최근 12주 중 글 쓴 주) | 5 |
| 소통·구독 (댓글·구독자) | 5 |

등급 경계는 위로 갈수록 어렵게: 준최1 29점 · 준최4 55점 · 최적1 75점 · 최적4+ 97점.
기준 블로그 하나(외부 분석 사이트 준최2)에 맞춰 보정한 값이라, 다른 사이트와 한두 단계 차이 날 수 있어요.

글 최적화 점수(100): 본문 1,500자 이상 30 · 사진 8장 이상 20 · 제목 15~40자 10 · 대표 키워드 본문 3~10회 20 · 소제목/인용구 10 · 동영상/지도 10.

네이버 공식 등급이 아니라 공개 데이터로 계산한 추정치예요.
