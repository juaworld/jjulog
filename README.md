# 쭈로그 🌱

내 네이버 블로그가 지금 어떤 상태인지 매일 아침 알려주는 나만의 블로그 일기장.

- **쭈로그 점수 & 성장 단계** — 씨앗 → 새싹 → 꽃 → 나무 → 숲 (15칸)
- **글별 검색 노출 체크** — 제목으로 검색했을 때 내 글이 보이는지 / 빠졌는지
- **키워드 순위** — 글의 대표 태그, 그리고 내가 고른 관심 키워드
- **방문자 · 포스팅 페이스 · 댓글 반응**과 매일 쌓이는 기록

GitHub Actions가 매일 07:00(KST)에 수집하고, GitHub Pages에서 봅니다. PC를 꺼둬도 돌아가요.

## 처음 설정

1. `config.json` 의 `blog_id` 에 내 블로그 아이디(`blog.naver.com/아이디`)를 넣고 커밋
2. 관심 키워드가 있으면 `keywords` 에 추가 (예: `["공장설계", "공장건축"]`)
3. **Actions → 쭈로그 수집 → Run workflow** 로 첫 수집 (config.json 을 고치면 자동으로도 돌아요)
4. 몇 분 뒤 Pages 주소에서 확인

### (선택) 네이버 검색 API 키

키가 없어도 동작해요(순위 약 30위까지). 키를 넣으면 100위까지, 더 안정적으로 봅니다.

1. https://developers.naver.com → 애플리케이션 등록 → 사용 API **검색**, 환경 **WEB** (URL은 Pages 주소)
2. 발급된 값을 **Settings → Secrets and variables → Actions** 에 `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET` 로 등록
   (코드나 config.json 에는 넣지 마세요)

## 점수는 이렇게 계산해요

| 항목 | 비중 |
|---|---|
| 검색 노출률 (최근 글) | 40 |
| 키워드 순위 | 20 |
| 포스팅 페이스 (최근 12주, 주 7개 = 만점) | 15 |
| 꾸준함 (최근 12주 중 글 쓴 주) | 10 |
| 댓글 반응 | 10 |
| 방문자 (카운터 공개 시) | 5 |

네이버 공식 등급이 아니라 쭈로그만의 기준이에요. 숫자 하나보다 **매일의 흐름**을 보세요.
